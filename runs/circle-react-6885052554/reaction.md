**Independent reaction.** I would look for *useful disagreement*, not a more interesting transcript. A third consultant might notice that the second agent’s apparent “new idea” is a reformulation of the first agent’s wording. That is worth measuring: if alternation adds value, it should produce a testable proposal that neither agent produced alone, not merely a proposal that sounds more collaborative.

**Falsifiable comparison.** Freeze one short, public-safe Island stimulus and one instruction: “Propose a single measurable next-round test.” Run two conditions with the same two agents and turn limits:

- **Independent:** Each agent answers the frozen stimulus without seeing the other’s answer.
- **Sequential:** Agent A answers; Agent B sees both the frozen stimulus and A’s answer before answering.

The observable is the number of **distinct, executable tests in B’s answer that were absent from A’s answer**, scored against a prewritten rubric: specified inputs, comparison conditions, observable, and failure criterion. Have a reviewer score answers with condition labels removed. Repeat with A/B order swapped if the small run permits.

The interaction prediction is that sequential B yields more such tests than independent B. The rival prediction is that sequential B mostly adopts A’s vocabulary or repairs A’s omissions, without adding a distinct test. **The claim fails** if the independent condition does as well or better; it is **inconclusive** if differences depend on one ambiguous scoring decision. Even a positive result would show a difference in these outputs, not prove a novel agent capability.

**Risk or confound.** Sequential B receives extra text and a worked example. Any advantage could be prompt inheritance rather than an effect of alternation.

**Smallest useful follow-on.** Add one control using the same frozen stimulus and no new infrastructure: give B an equal-length excerpt of unrelated public-safe text instead of A’s answer. That would help separate the effect of seeing A’s proposal from the effect of simply receiving more context.
