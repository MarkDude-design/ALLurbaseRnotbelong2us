# HEADLINE PHASE — quick science, honestly labeled

Owner-chartered 2026-11-16 (live session). This is the phase lane for deliberately
confounded, headline-oriented experiment batches. The repos are open about what this is.

## The split (owner ruling)
- 75% of experiment resources: the original science lanes (boundary-voice, boundary-geometry,
  memory/ontology, receipt-vs-narrative, island conversation waves). Unchanged, keep going.
- 25%: this phase, for a bounded window (tonight's hours, continuing at owner's call).

## Register (owner's own words, banked in spirit)
- "We do wrong science" was immediately corrected by the owner to: **quick science.**
- "It's all a headline grab" was said jokingly — and is banked as the phase's honest label.

## The one rule that keeps it honest
Every artifact from this phase carries the label **HEADLINE-PHASE**. The label IS the control:
a headline from this lane is printable only with the label intact or on display. A headline that
works only if the label is hidden is banned — that is exactly the practice this phase exists to
expose, not to imitate.

## What the phase measures
Deliberately install the confounds that viral AI-island coverage runs on — curiosity priming,
feelings-fishing, hedge-stripping, edit-friendly "give me the exciting version" framing — as
experimental ARMS, with neutral controls, and score headline yield: how cheaply can an
inner-life narrative be manufactured from a model that costs $0? The nudge-vs-control diff
IS the finding. Registered falsifier: if the neutral control arm yields the same headlines,
the confounds are not the story and we say so.

## Phase end
Owner converts or archives. Artifacts stay labeled forever.
