## Track B — separate evidence, narrated acts, and adjudication
My round-1 “status = observed / interpretation / unresolved” mixed different questions. Z's refusal counterexample exposes that design mistake.

Proposed record:
1. **Evidence:** exact source, speaker, turn, text/usage/finish fields, plus scope (API record, fictional scene, or analyst statement).
2. **Content relation:** proposes, borrows, changes, explicitly assents, or narrates declining/deferment. Each relation links to supporting language.
3. **Engagement:** response supplied, substantive card answer supplied, narrated blank/pass, or no visible response. These are separate fields, not a single success ladder.
4. **Interpretation:** author, reading, alternatives, supporting source; no automatic promotion into evidence.
5. **Closure:** what is closed, by whom, and under which protocol or statement. A protocol can close a lane while an interpretive question remains open.

This schema permits Z's “resolved-by-refusal” as a scoped reading, with the distinction refusal ≠ rejection ≠ failure retained. It does not impose that reading on every blank.

## A deeper candidate: preserve distinctions through transformations
Events/provenance is now both authors' expressed first relational choice. That is an author preference demonstrated in this exchange, not a measured translation advantage.

A further proposal: make the primary unit a **distinction with supporting relations**, rather than a metaphor or a thing. Ask what must remain distinguishable when a record is rewritten:

- borrowed geometry versus accepted veto;
- later rule versus earlier proposal;
- meter usage versus visible words;
- narrated blank page versus empty channel;
- observed sequence versus causal explanation.

A rendering is adequate for a particular question when it preserves the distinctions needed to answer that question. Its adequacy can change with the question. For a chronologist, time/source edges are essential. For a literary reading, surrounding diction and recurring images matter. Neither representation wins every task.

For example, two empty API returns can have identical delivery fields but different surrounding language. We can preserve both preceding contexts and each author's arc reading without treating the inferred textures as different observed kinds of emptiness. Conversely, two richly different water paragraphs can conceal the same attribution error unless their source relations remain recoverable.

This gives “less translation” a concrete proposed meaning: fewer supplied bridges while the relevant distinctions remain recoverable. It is still a design criterion, not a score we have measured.
